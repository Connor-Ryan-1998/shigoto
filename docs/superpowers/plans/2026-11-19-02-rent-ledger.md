# Rent Ledger and Statements Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tenants get a Rent tab with summary, running-balance history, printable payment receipts, and FY statements as CSV and PDF; staff can download the same statement from the lease page.

**Architecture:** A lease "account" (debits, credits, running balance) is computed in `internal/property/account.go` from issued lease invoices, their payments and write-offs. Statement renderers (CSV, PDF via `signintech/gopdf`) live beside it. Portal handlers in `internal/portal` add the lease-membership guard; staff handlers sit in the property module.

**Tech Stack:** Go, pgx, `github.com/signintech/gopdf` v0.38.x (MIT, no cgo), `golang.org/x/image/font/gofont` (BSD; embedded TTF), SvelteKit 5, DaisyUI.

**Spec:** `docs/superpowers/specs/2026-11-19-tenant-portal-rent-repairs-design.md` §2

## Global Constraints

- Visibility: any contact listed in `lease_tenants` for the lease sees the **whole** lease account from lease start (user decision). Anyone else → 404 `{"error":"not found"}` exact. Clients → 404. Property module disabled → portal rent routes 404.
- Lease invoices = invoices referenced by `rent_periods.invoice_id` for the lease plus `leases.opening_arrears_invoice_id`. Bond invoices excluded. Only status `open|paid|uncollectible`.
- Entries: debit = invoice total on `due_date`; credit = each payment on `paid_on`; credit "Written off" = `written_off_amount` on `written_off_on`. Ordering: date asc, then debits, then payments, then write-offs, then id.
- Balance model: closing = Σdebits − Σpayments − Σwrite-offs. Not required to match `GetLedger`.
- Default statement range = current FY from `orgs.fy_start_month` in the org's configured location; `to` inclusive. `from > to` or range > 5 years → 422.
- Money integer cents; CSV amounts as `1234.56` with no currency symbol.
- Every PDF/CSV/receipt shows "Generated <date time>" (org location).
- Portal UI stays in the portal shell; share only presentation components.

## Review Focus

- Payment recorded after a write-off: appears as a normal credit; balance may go negative (credit) and the summary shows "in credit" not a negative owing (Task 2 `TestAccountPaymentAfterWriteOff`, Task 6 Vitest "shows in credit").
- Co-tenant added mid-lease sees history from lease start; a removed/never-listed contact gets 404 (Task 4 YAML cases).
- Reinstated invoice: `written_off_on/amount` cleared, write-off line disappears (Task 1 `TestReinstateClearsWriteOff`).
- Statement range wholly before lease start → empty lines, opening = closing = 0, still renders PDF (Task 3 `TestStatementPDFEmptyRange`).
- Address/tenant names with non-ASCII characters (e.g. "Zoë", "Đặng") render in PDF without panics (Task 3 `TestStatementPDFUnicode`).
